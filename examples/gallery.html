01 / Quick start

Describe once. Render anywhere.

Chart construction, layout, and output are separate. Your data becomes a semantic cell grid, then any renderer can turn that grid into text, ANSI, accessible HTML, or a multipart email.

[01]

Describe

Choose a chart factory and pass ordinary typed data.

[02]

Lay out

Set width, height, and strict ASCII or richer Unicode glyphs.

[03]

Render

Send the same grid to the terminal, browser, or inbox.

pnpm add @ascii-graphs/core@next @ascii-graphs/renderer-text@next

import { bar, layout } from "@ascii-graphs/core";
import { renderText } from "@ascii-graphs/renderer-text";

const chart = bar({
  title: "Monthly revenue",
  data: [
    { label: "Jan", value: 42 },
    { label: "Feb", value: 68 },
    { label: "Mar", value: 91 },
  ],
});

const grid = layout(chart, { width: 42, charset: "unicode" });
console.log(renderText(grid));
02 / Outputs

Built for hostile surfaces.

No DOM or terminal dependency in core. Output remains useful without color, JavaScript, CSS, or even Unicode.

>_

Plain text

Logs, Markdown, snapshots, and redirected CLI output.

\x1b

ANSI

Semantic 16-color, 256-color, or true-color terminals.

</>

Accessible HTML

Escaped markup with descriptions and semantic data tables.

@

Email

Matching plain-text and HTML MIME parts from one grid.
