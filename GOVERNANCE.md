# Governance

The project currently uses a maintainer-led governance model. Maintainers decide
the roadmap, releases, public API, and contributor access while seeking
community input for consequential changes.

Contributors who demonstrate sustained, constructive participation may be
invited to become maintainers. Maintainer changes and major governance decisions
will be recorded publicly.

Compatibility, accessibility, security, and portability take priority over
adding more chart types. Material public API changes should have a proposal and
a clear migration path once the project reaches version 1.0.
